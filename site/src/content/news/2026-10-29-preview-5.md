**FerMatter 0.11.0 Preview 5** is available for macOS, Windows and experimental Ubuntu. Get the installers and Homebrew/APT commands from [Download](https://fermatter.github.io/download/).

## Workspace and rendering

Library and Source share consistent toolbar positions. You can [exclude tables and selected environments](https://fermatter.github.io/guide/extraction/) from Library cards while preserving the original document.

Windows fixes preserve menus after closing Instant and keep single SVG copies as vector artwork in LibreOffice Impress. Ubuntu fixes native window appearance and the launcher icon.

## Updating

Preview 5 includes an Updates panel with optional daily checks enabled by default. Existing off settings are preserved. The stable update feed is still inactive, and Preview releases are installed manually or through Homebrew/APT.

If you use Preview 4 or earlier, [update once manually](https://fermatter.github.io/guide/updates/) to get the new interface. Existing projects, settings and drafts are retained through the permanent app-ID migration.

See [resolved issues](https://fermatter.github.io/resolved-issues/) for individual fixes and platform versions. This remains a preview: macOS is not notarized, Windows is unsigned, and Ubuntu remains experimental.
