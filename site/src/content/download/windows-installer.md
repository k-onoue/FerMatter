title: "Windows installer notes"
description: "Opening the unsigned Windows preview installer."
---

Install the EXE, then open FerMatter from the Start menu. WebView2 runtime setup is included.

For an unknown-publisher or SmartScreen warning, check the release and checksum above. If you trust this preview and Windows permits it, choose **More info → Run anyway**. [Microsoft's guidance](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/publish-first-app#step-6-handle-smartscreen-for-new-apps).
