---
title: "Windows installer notes"
description: "Opening the unsigned Windows preview installer."
---

Run the installer, then open FerMatter from the Start menu. It installs for your Windows account and includes the WebView2 runtime installer. LaTeX and Typst are installed separately.

Windows may show an unknown-publisher or SmartScreen warning. Check the release and SHA-256 checksum linked above before continuing. If you trust this preview and Windows permits it, choose **More info → Run anyway**. [Microsoft's SmartScreen guidance](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/publish-first-app#step-6-handle-smartscreen-for-new-apps).
