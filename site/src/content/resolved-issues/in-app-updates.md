## What changed

Updater-enabled builds show a colored indicator when a newer stable version is available for the current OS and CPU. Automatic checks start on by default; an existing off setting is preserved. Downloads and installation remain separate user actions.

## What to do

Existing public previews require a [manual first update](https://fermatter.github.io/guide/updates/). Source builds include the interface, while installation requires an installed package. The stable update feed currently offers no update; a merged fix alone does not trigger the indicator.
