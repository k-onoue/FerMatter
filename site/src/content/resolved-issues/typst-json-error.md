## What changed

Typst warnings no longer interfere with parsing the query response used by extraction.

## What to do

The fix is already in [macOS Preview 1](https://github.com/FerMatter/fermatter.github.io/releases/tag/v0.11.0-preview.1) and later. If it persists, check [compiler requirements](https://fermatter.github.io/guide/requirements/).
