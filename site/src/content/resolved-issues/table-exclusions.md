## What changed

Users can customize the excluded environments in the project’s extraction settings file. This controls card extraction without changing the source document.

## What to do

See [extraction rules](https://fermatter.github.io/guide/extraction/) for configuration. The feature is in [Windows Preview 2](https://github.com/FerMatter/fermatter.github.io/releases/tag/v0.11.0-windows-preview.2) and later; macOS and Ubuntu packages still await it.
