## What changed

The DEB now installs the FerMatter icon at standard desktop-theme sizes. GNOME can display it in application search and the launcher.

## What to do

Update to Ubuntu Preview 5 or later using the [APT commands](https://fermatter.github.io/download/#ubuntu). The package refreshes the desktop icon cache during installation. Ubuntu remains experimental.
