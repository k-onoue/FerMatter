## What changed

Existing project locations are preserved. A new Windows installation defaults to the local user folder’s `FerMatter` directory, outside OneDrive.

## What to do

Update to [Windows Preview 4](https://github.com/FerMatter/fermatter.github.io/releases/tag/v0.11.0-windows-preview.4) or later. See the [Download page](https://fermatter.github.io/download/#windows) for installation.
