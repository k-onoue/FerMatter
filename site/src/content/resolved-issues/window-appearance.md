## What changed

The Windows preview fixes native titlebar spacing and synchronizes window/menu appearance. Ubuntu Preview 5 includes the corresponding spacing and appearance changes. Windows Preview 5 also preserves the main menus and selected theme after closing Instant.

## What to do

Update Windows to [Preview 2](https://github.com/FerMatter/fermatter.github.io/releases/tag/v0.11.0-windows-preview.2) or later; choose Preview 5 or later for the Instant menu fix. On Ubuntu, install Preview 5 or later. See [appearance settings](https://fermatter.github.io/guide/appearance/).
