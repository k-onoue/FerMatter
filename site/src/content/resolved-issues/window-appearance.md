## What changed

The Windows preview fixes native titlebar spacing and synchronizes window/menu appearance. The corresponding Linux spacing and appearance changes are in source builds and still await an Ubuntu package.

## What to do

Update Windows to [Preview 2](https://github.com/FerMatter/fermatter.github.io/releases/tag/v0.11.0-windows-preview.2) or later. See [appearance settings](https://fermatter.github.io/guide/appearance/).
