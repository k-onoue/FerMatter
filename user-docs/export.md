Choose the format and **Output font size** (1–200 pt), then copy (`⇧⌘C`), export (`⇧⌘S`) or drag the preview.

For PowerPoint, use **SVG**. PDF artwork can be rasterized when PowerPoint exports a `.pptx` to PDF. [Reported issue](https://learn.microsoft.com/en-ie/answers/questions/5701486/recurring-issue-save-as-pdf-converts-vector-graphi).

## Output size

**Item override → Project → App default**. Click **Default** to inherit the next setting. Instant saves its defaults separately.

Size applies to copy, drag and export. Figures scale as a whole, including labels.

## Several equations

Copy selected cards to paste separate images. File export saves one selected image; multiple-image dragging depends on the receiving app.

## Re-edit SVG

**SVG → Open SVG / drop into FerMatter → Edit**

SVG exports carry equation/template source; other apps may strip it. Keep the original SVG. Project imports, packages and fonts may still be needed.
