1. Double-click an equation in **Library** (`⌘E`).
2. Edit its source and wait for the preview.
3. Save (`⌘S`) to create a **Custom** variant, or copy the preview directly.

The original card and manuscript stay unchanged. Use [Source mode](source-editor.md) to edit project files.

- **Output size** and the color picker apply to the copied/exported image. **Reset color** restores the source color.
- The preview can export an unsaved draft; copy and drag wait until it matches the current input.
- **Format** (`⇧⌥F`) formats this variant only.

## Type less

- Completion includes commands defined in project files; installed packages and generated definitions are not fully indexed.
- Tab/Shift-Tab moves between inserted argument fields.

[Choose size and format](export.md).
