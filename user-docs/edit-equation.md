# Make a version for your talk

1. Double-click an equation in **Library** (`⌘E`).
2. Edit its source and wait for a successful preview.
3. Save (`⌘S`); the edited equation appears as a **Custom** variant.
4. Copy the preview or the saved card into your slide.

- The original source card and manuscript stay unchanged.
- Choose an output color beside **Output size**: **Default** swatches, **Color Picker**, **History**, or **HEX**. **Reset color** restores the source color. The chosen color is saved with the variant and included in copied/exported artwork.
- The preview exports the successfully compiled draft, even before saving.
- Changed source or color hides an outdated preview while compilation is pending.
- [Source mode](source-editor.md) edits the actual project files; use it when you intend to change the paper.

## Type less

- Type a prefix such as `\f` or `sq` to see command suggestions.
- Use `↑`/`↓` to select, Return/Tab to insert, and Escape to dismiss.
- Use Tab/Shift-Tab to move between inserted argument fields.
- Project-defined commands contribute suggestions; installed packages and generated definitions are not fully indexed.
- [Export settings](export.md) control the copied image's size and format.
- **Format** (`⇧⌥F`) formats the equation or figure source; `⌘Z` restores the previous text. It affects this variant only. See [formatters](source-editor.md#editing-shortcuts).
