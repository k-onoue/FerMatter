Open **Settings** (`⌘,`). **Projects** chooses the default folder and output size; **Editor** selects automatic or manual saving.

## Compiler tools

[Requirements](requirements.md#tool-discovery) covers executable paths and detection. For external edits to `tools.json`, choose **Reload**; invalid settings keep the last valid configuration.

[Shortcuts](shortcuts.md#manage-shortcuts-and-themes-as-files) and [Appearance](appearance.md#manage-shortcuts-and-themes-as-files) cover JSON editing, reload, import and export.

## Updates

This version updates manually. Quit FerMatter and replace the app in Applications; projects, settings and drafts live outside the app bundle.
