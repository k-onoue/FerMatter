## Missing equations

- Extraction reads literal source; equations generated by macros, loops or functions may be missing.
- LaTeX supports common math environments and literal `input`/`include` paths. Custom environments, conditional definitions and body-local macros may need adjustment.
- Typst supports literal `$…$` and `#include`. Counters, state, queries and document-wide templates may not reproduce in isolated exports.
- **Rescan** updates the Library after external changes; automatic rescanning is not available.

## Failed rendering or navigation

- Check **Project Settings** for the main file/compiler and **Settings → Tools** for [required tools](requirements.md). Open the failed item's log.
- Failed PDF builds keep the old document and navigation snapshot. Rebuild successfully to navigate current edits.
- Generated or ambiguous locations may have no PDF target; use the Library card or Source preview.
- If pasted text is misdetected, choose an explicit [input mode](new-project.md).

## Not available

PDF/OCR input, cloud sync and in-app update downloads are not included. Drag compatibility depends on the receiving app; try copy/paste or file export.

## Local data

- Opened folders stay in place. New projects and imports use the configured default project folder.
- Settings, drafts, caches and exports live under `~/Library/Application Support/Slide Math/Rust Preview/`; the name is retained for compatibility.
- Removing the app does not remove project folders or support data.
