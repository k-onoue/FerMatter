# Product page assets

- `app-light.jpg` and `app-dark.jpg`: actual native Mathlidelux screenshots with
  only the synthetic `examples/demo-paper/` project visible. Captured at full
  background opacity to keep other windows out of the images.
- `trajectory.svg`: rendered by the application's TeX worker from the demo's
  trajectory equation. It consists of vector paths and has no external fonts.
- `icon.svg`: original vector mark created for the product page. The native app
  does not yet use this as its application icon.

Do not reuse development screenshots from private projects here.
