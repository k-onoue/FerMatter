FerMatter — stable candidate

This candidate is ad hoc signed, without Developer ID signing or Apple
notarization. Its PKG installer is unsigned. Candidate validation and release
channel are separate from signing status.

Install by dragging FerMatter.app into Applications, or use the PKG installer.
If macOS blocks the official download, open it once, then use System Settings
> Privacy & Security > Open Anyway for this app if macOS offers that option.
Keep Gatekeeper enabled. See https://support.apple.com/102445.

Quit the previous version before replacing it. Existing projects, drafts and
settings remain in their original locations. macOS may request folder access
again after the app identifier or ad hoc signature changes.

Compiler tools are installed separately: https://fermatter.github.io/download/.
This package is a validation candidate, not an announcement of stable support.
